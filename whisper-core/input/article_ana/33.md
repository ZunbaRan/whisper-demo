# 闲鱼能代上架了？这跟直接给我塞钱有啥区别？
图片

大家好。

昨天在朋友圈看到一哥们@高百烈，说到他用了一个很新颖的服务，叫“闲鱼代上架”。

图片

@高百烈 朋友圈

我很感兴趣，就去问了下，这个“代上架”是咋操作的？

哥们也坦诚，跟我讲了一番操作：

1、“代上架”的人来你家里，帮你把那些，搞不清楚是什么时候买的，过期的，或者用不到的东西，一一统计，还有哪些有价值，哪些能卖，并且把有价值的筛选出来，统一拍照、整理，然后就回去了，东西留在你家。

2、“代上架”回家后，给商品写文案， 包括入库，上架，运营、擦亮这些动作，都是他负责。

3、等东西卖出去，“代上架”会通知你：“这个卖出去了，可以把它放到家门口了，我叫快递来取。”

4、卖出去之后，“代上架”扣完自己的那部分分成，剩下的钱直接微信转给你。

图片

图片

整个过程，咱只需要做三件事情：

①花一个下午的时间，确认家中所有二手闲置的库存；

②在微信收到通知后，将卖出的物品放到家门口，等待快递取件；

③动动手指， 确认收款；

全程就三步，再傻的傻瓜都知道怎么操作。

图片

我一发到公司群，我靠，同事们都疯了，还有这种服务？？？

赶紧端上来吧！闲鱼上架可太麻烦了！！

图片

有同事说，家里有很多临期的护肤品、化妆水，还有一些衣服穿了没几次，没拆封，直接扔了又太浪费，想着能不能当临期的东西卖掉？

图片

还有我们公司的HR。

最近办公室正在搬家，前段时间办公室装修，整出了一堆闲置物品。挂闲鱼要花时间，一个个拍照、上架、和人谈，太麻烦了，闲置的东西放着是浪费，丢了又可惜，处理起来又麻烦，非常痛苦。

图片

结果我上闲鱼一搜，才发现没有”代上架”服务，只有一个服务叫“代挂”。

所谓“代挂“，是指你把物品上架到闲鱼后，他可以帮你把一样的商品重新上架一份，有点像是“寄卖”的形式，好处是增加你的曝光机会，同时定期刷新商品曝光度。

但到最后，商品的整理，拍照上架、定价，以及买卖过程中与买家的battle，发货，还是要你自己上场去完成，和代上架的便利程度差的实在太多了。

我不死心就问那哥们：“你这代上架服务是怎么找的？”

他说是他小舅子干的。

我当时就把29米大刀收回来，说：“你....小舅子怪有商业头脑的啊，发现了一个巨大的市场空白！”

对于有一堆闲置物品的人来说，他们最需要的就是省心，能腾出空间，还能赚点小钱啊。

图片

但我又转念一想，不对，既然这个服务这么有用，为啥除了他大舅子，没人做呢？

自古以来，杀头的买卖有人做，赔本的买卖没人做，这个项目没人做，一定是有硬伤。

想了想明白了，闲鱼代上架这个服务，真的只能是这哥们的小舅子做。

为啥呢？

首先从卖家的角度看，如果开始做闲鱼代上架这个服务，肯定会有很多人让你上门去做。

因为不收上门费，只分成，相当于买家是无本买卖，卖家承担白跑风险。

图片

然后卖家就会遇到什么情况？

到顾客家里一看，全是歪瓜裂枣，一堆破烂，比如用了十年的戴森吸尘器，卖不了几个钱。

图片

或者很多非常便宜的零碎东西，比如过期两年的爽肤水和牙膏，你转手卖个20，就算抽一半也只能赚10块，不够地铁钱的。

你卖吧，不仅浪费时间，还可能没人要；你不卖吧，又驳人家面子。

哪怕收上门费，能收多少呢？

一二百块撑死了，到最后成了跟楼下的废品回收的抢生意了。

粗略估算了一下， 在北京上海这样的大城市，上门一趟，整理出来的闲置物品，如果残值达不到几千块，哪怕抽两成，算上卖出去后续的维护成本、上架的人力成本，这单都挣不了几个钱。

这能赚个啥？

还不如拿一样的时间去跑外卖。

图片

所以卖家要能赚到钱，你的客户必须满足三个条件：

第一，闲置足够多；

第二，闲置品单价足够高；

第三，闲置品残值率高，有转卖价值。

基本上闲置也限制在这几个类目：美妆、服装、家电、数码用品、奢侈品，和小众收藏。

图片

那么，符合这种画像的客户群是谁？

很简单：有钱人、阔太太、网红、明星。

这些人，要么平时过度消费，囤积过多，要么家里有大量礼品、样品、样衣、来不及用。

而对寻常人来说，家里的闲置物的数量、单价和成色，都很难支撑这种服务模式，

所以，闲鱼代上架，适合服务高端客户。

但问题也来了——高端客户最害怕的是什么？隐私泄露。

明星、网红、有钱人，他们隐私的价值，很可能比闲置物品本身还高。想象一下，有人跑到有钱人，明星，网红家里，把每个角落翻个遍，库库库拍下所有东西。

在这个过程中，发现什么前任的验孕棒，二手的飞机杯，可能某个房间还有两个小三五个私生子，3本不孕证明，8本不同国家的护照。

这还卖啥闲置？直接开直播，库库收米效率都更高。

所以高端客户，不可能让一个陌生人进家里翻闲置。

如果要做这种服务，这个事，只能是很熟的人来做，比如我那个朋友的小舅子。

图片

如果不是很熟的人也能做，你得有办法获得高端客户的信任，而且是能进他家的那种。

那问题就来了，我特么都能获得明星、网红、有钱人的信任了，都能进他们家里了，我做点啥不好？？？

我做二奢，做汽车，做医美，做大健康，做汽车，做身心灵，哪个不比上闲鱼卖二手闲置挣钱？？？

这就是这个行业最大的Bug。

闲鱼二手代上架，最大的门槛是筛选到高端客户，这个生意才成立。

因为只有高端客户才有大量有价值的闲置物品能卖。

而如果，你有了这部分客户，又有太多能赚到钱的路子，通过做闲鱼代上架挣钱，效率太低。

图片

不过相对于什么医美大健康二奢之类赛道来说，闲鱼代上架这个服务的好处是，还没有人做。

现在真的有很多明星都是自己在闲鱼上架的，或者交给小助理做。

真事儿，我们公司同事有一次在闲鱼买衣服，那个地址是汤臣一品发货的，名字是某明星，我都惊呆了。

其实真说闲鱼代上架，做二奢的能不能做这个？能做。做管家的能不能做这个？也能做。整理师呢？也能。明星助理呢？也能，但是目前都没有人去做。

可能因为这领域他们不够专业，也可能是利润太薄，懒得碰。

但正因为没人碰，就意味着有机会。

如果你认识一些有钱朋友，又比较喜欢玩闲鱼这种二手平台，知道怎么捣鼓货，估估价，平时又能给他们传递靠谱的印象，其实真可以尝试做这个生意。

看似小众，但利润空间并不薄。

因为本质上，你赚的是“有钱人闲置”和“普通人消费能力”对于价格的认知差。

再说的夸张一点，本质上就是弥平“朱门酒肉臭，路有冻死骨”的空间。

把那些已经过时的“朱门酒肉”搬出来，用低价卖给那些路边等着取暖的普通人，让普通人以更便宜的价格买到朱门酒肉。

图片

想要做好这个生意，需要具备几种条件：

①擅长拍照，能快速给闲置估价，并且熟悉二手平台的操作规则。

②懂得如何服务有钱人，让他们觉得省心、方便；

③有一定的行业人脉资源，不行的话，从身边的朋友开始尝试。

不过，这个职业如果真发展起来了，有钱人省了心收了元子，普通人买到了高性价比的东西，

唯一的“受害者”可能就是那些大牌电商了。

原本消费降级，贵东西不好卖了，这些大牌已经在各大平台的价格战中挣扎。
