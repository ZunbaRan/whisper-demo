# 蜜雪冰城，在机场也只贵一块钱？
图片

家人们， 今天我正刷着手机，突然被🍠的推送吓了一跳。

蜜雪冰城进机场了，而且只比外面贵了一块钱？卖的比机场的瓶装水还便宜，本来想进便利店买饮料，都被拐出来了：既然都是这点钱为啥不买现做的呢？

图片

我一看评论区，好家伙，不仅是入驻机场，蜜雪冰城入驻高铁站，也成了当地吹锣打鼓，奔走相告的大新闻。

图片

大家都在口口相传，乡亲们，咱家门口的机场火车站有蜜雪冰城啦😭 ！而且只贵一块钱，终于不用在高铁站点那几十一杯还贼难喝的破饮料了😭！

图片

说到这儿我就一肚子火🔥，上周跟同事出差去泰安，在火车站随便吃了顿某知名连锁快餐，结果四个人的账单一出来，好家伙，捏妈300多！这要是在公司点，300块钱够8个人吃的了，他怎么敢这么贵啊？？？

图片

所以我到了火车站机场，我都是能饿着就饿着，不饿死坚决不点菜，有一次没忍住点了碗牛肉面，那汤上也就两块鼻嘎大的牛肉，居然要了我45！其他商家，不把价格往上翻个一倍，都不好意思开门做生意。

但蜜雪冰城，怎么只贵了一块钱呢？

评论区的网友更是补充：泰山顶上最便宜的水，也是雪王。

是的，是真的比水便宜，泰山顶上的矿泉水都要5块钱一瓶啊！

图片

神奇的是，蜜雪冰城价格这么便宜，它Low吗？好像也不Low。

前两天和斯斯回徐州时，看到一条街上，各种叫不上名字的奶茶店。我特别想吨吨一杯，但看着牌匾五光十色，担心喝下去元素周期表给我凑齐了。

这时，抬头看到一家蜜雪冰城，卧槽有救了，让我联想起有一次在韩国街头，餐厅的门头看不懂，而且都是又贵又难吃，这时路边升起一个M记标识，我立马鼻头一酸😭

图片

神奇的是，我侯马老家的亲戚也说过，有次去上海，看到了路边那种精致的冰淇淋饮品店，大理石门头散发着意大利风情，让人真不敢进去！都知道沪币汇率已经快到1：3了，担心进去就得掉层皮。

就在这时，地平线上升起一个白胖子——太好了，咱有救了😭

图片

真的，一个品牌，是如何做到，在老家让人放心，在大城市有性价比呢？仔细想想，没几个国产品牌能做到这点。



恐怖的成本控制能力

我之前写过，表弟在老家开一家鲜果茶店，他说过，做一杯杨枝甘露卖18块，光芒果成本就得7块😭，这还不算他剥芒果的人工。那蜜雪冰城是怎么做到三四块一杯的柠檬水，还不翻车呢？

一番调查才发现，光是为了把柠檬水的价格压下来，蜜雪冰城就在全国建了好几个柠檬供应基地。在柠檬的主产区，重庆潼南，蜜雪就深度合作了15万亩的果园。

图片

图源：南方都市报

这里有一家，名字一看就跟雪王脱不了干系的公司，叫做雪王农业，从分拣柠檬，冷藏柠檬，给柠檬套袋子，打包运输，全年要吞吐柠檬10万吨以上。

从田地采摘到装进收运车、拉到工厂清洗和消毒，再进入冷藏仓库。每个柠檬都会拥有自己的“身份证”。

图片

图源：南方都市报

冷知识，现在的🍋，已经不是靠人工筛选了，而是靠射选仪，每个柠檬经过的时候，用摄像头给你咔咔拍上40张照片，把柠檬的外皮、果茎、大小、重量啥的都给记得清清楚楚。

这些柠檬啊，按品相被分成不同的类别，品相最好个头又大的（叫A级果）被送往各地门店，准备接受一顿暴打，最终成为大家手上拿着的柠檬水。

B站UP主敬汉卿去蹲点蜜雪，天天在后厨跟个柠檬成精似的，又是切片又是称重的，蹲在柠檬框旁边摸来摸去，发现人家进的柠檬，那一个个都跟小拳头似的，品相贼好，最离谱的是价格还贼便宜。

图片

图源：B站敬汉卿

而门店从蜜雪总部进货的橙子，那叫一个饱满圆润，就这品相，在水果店里怎么也摆在第一排。而它的进货价格，居然比当地超市里头，最皱了吧唧的橙子还便宜。

图片

图源：B站敬汉卿

去蜜雪，就能用难以想象的低价进到品质贼高的鲜果，作为水果星人的我酸了。

图片

不光是柠檬，什么橙子、茶叶、咖啡豆，蜜雪都追到源头去抓，这样的好处是，可以管控源头的质量，同时也可以把中间商成本砍去，整体成本控制到最低。

图片

同时，蜜雪冰城为节省物流成本也是绞尽脑汁。

有一个成本，大家肯定意想不到，就是门店里头装糖浆那个塑料桶，乍一看跟金龙鱼调和油似的那个。

图片

这个塑料桶用量非常大，每家门店都要有，但蜜雪冰城在采购时就发现，这玩意儿太贵了！

不是桶贵，是运费贵，冷知识：物流会按体积收费！哪怕桶里装的是空气，这么大的体积运费也不低。

所以，为了在桶上省钱，蜜雪冰城从工厂直接采购塑料粒，就像压缩毛巾一样，等运到蜜雪冰城的工厂后，再统一吹制成糖桶，进一步完成灌装后，再配送到全国各地的门店。

光靠这一招，蜜雪把桶的成本砍掉了大半。

图片

可以说，整个供应链里头，从去产地收柠檬，到自己吹塑料桶， 能省前端成本的环节都省了，这样才能帮门店省钱（PS：蜜雪冰城对加盟商是免物流费的）

蜜雪在省钱上花样百出，这儿省一毛那儿省两分，恨不得把一块钱掰成八瓣用。但在捐钱上毫不犹豫，前两天日喀则地震，二话不说就掏出1千万。

图片

前两年郑州暴雨那一回，作为河南本土企业，除了捐钱，更是迅速给医院、派出所运送救灾物资，共计3480万，胖嘟嘟的雪王上前线了。

图片

（7.20 郑州特大暴雨，蜜雪运送物资）



你见过蜜雪冰城倒闭吗？

蜜雪冰城给人可靠的印象，还有一个原因：店铺很少倒闭。

仔细回想一下，你见过蜜雪冰城倒闭吗？

理论上说，全国开的最多的蜜雪冰城，即使关店率和别人都差不多，倒闭的总店数也该是最多的，但我印象，就没见过蜜雪冰城倒闭。

不倒闭的好处，可太多了，一方面，这样省下了很多减少了许多开店、关店和调试的成本，也不会因为反复装修而浪费加盟商和总部的培养成本。

另一方面，店一直亮着，人家消费者才会一直惦记你，如果小朋友喝得好好的，突然倒闭了，那是不是也会留下这个牌子不靠谱的印象呢？

图片

蜜雪冰城是怎么做到，门店最多，却很少倒闭的？

查了很多资料才发现，蜜雪冰城不是那种噶一刀加盟费走人的类型。

比比找来了蜜雪加盟的材料，意外发现：蜜雪冰城的加盟费非常便宜，一线城市每年只需一万块钱，小县城每年的加盟费只需要7千多块。

图片

说到这儿，就想起前几天写过的那个，负债开个奶茶店，结果倒欠40万，店还开不下去了的悲惨故事。

现在市面上许多快招品牌，听着诱人，可真上手才知道吓人：加盟费动辄十几万，啥都没干你就先背上了贷款。

蜜雪冰城加盟费不贵，但对加盟商的筛选极为严格，你指望把钱往桌上一拍就领钥匙？没门儿，第一家店必须自己亲自打理，或者和对象一起干，想请店长都不行。

图片

他们整了好多轮面试，审核，目的就是为了筛选出那些投入大量时间精力经营店铺的人，绝对不把店放给只想两手一瘫，躺着赚钱的人。

图片

图片

而且，蜜雪冰城在开店时对区位选择也十分严格，如果位置不好宁愿放弃。

所以，别看蜜雪冰城的门店数量，甚至超过了麦当劳，但他们其实是克制着开的。查了下数据，蜜雪冰城加盟申请数量有420万份了，他们门店的申请通过率，还不到5%。

100个人想开店，最后能开成的就4个人，这成功率比相亲还低。

图片

所以，为啥蜜雪冰城很少倒闭？

道理很简单，那些无法长期经营的，位置不好的店，没有恒心的店主，从一开始就被蜜雪冰城筛选掉了。

怎么能一直打胜仗？

就是只打有把握打赢的仗，长期主义，大道至简，就这么简单。

图片

我还去采访了几位蜜雪冰城的店主，深入交流后，发现了一个很有意思的现象：

蜜雪冰城店的店主，对挫折很钝感。

比如我问一个，刚开业两天就遇到门口修路的店主：“开店遇到了什么困难？”

“没什么困难。”

图片

我？？？？你这店开了没多久，门口就修路了，顾客都看不到你的招牌。想买杯4块钱的柠檬水，得蹦过三个大土坑，比那超级玛丽吃个金币还难，白天店里都没啥人了，这不叫困难？

他却说：“门店来不了人，我就想外卖怎么做好呗，方圆5公里我自己送，晚上凌晨1点我也开着，周围人凌晨想喝的时候， 只有我这还开着，不就记住我了？”

我说：“那么晚啊！你下班都几点了？”

他：“ 能倒班就倒班，实在累了就熬一熬，总部也会派人来店里帮忙，帮我收银、干活，手把手教我鼓捣新品，还会拉着大雪王在门口搞活动，看他们这么拼，我也挺被感染的，所以遇到问题，一个个解决就是了。”

我聊完感觉：你从他嘴里听不到我好难啊！我好惨啊！没有，没有诉苦，抱怨。

这个不行，就试试那个，总之就是一定要把这个事情做好，只要挺过去了，就把困难忘了。

比比想起来自己，之前碰到烂人烂事，就会陷入自我折磨，进入内耗，反复在内心中拷问自己，拷打外部世界，翻来覆去，眼一闭一睁，哦豁4点了。

开蜜雪冰城的人，没有内耗，普遍秉持着一种非常实用主义的生活态度：遇到问题，就去解决；解决不了，想想其他招。

真正的文化输出

极致的成本控制，加上朴实的加盟商文化，使得蜜雪集团已经开出了45000家店（包含旗下咖啡店幸运咖），这仅仅是20年的成就，要知道麦当劳用了70多年，也没开出这么多。

不仅是中国，我前阵子去韩国，发现蜜雪冰城的价格也不贵，在当地常见的，又贵又齁甜的台式茶饮店里，算是一股清流。

图片

马来西亚的网友说，很多餐厅都有规定，不点餐就不让坐，蜜雪冰城不一样，没有强制消费，就算不买东西也能进去坐坐。

在印尼更夸张，蜜雪冰城已经成了打卡地了，一放学就挤满了成群结队的小学生，而且他们都爱在蜜雪冰城过生日，就跟咱们小时候非要去肯德基、麦当劳过生日一样。

蜜雪冰城在很多国家，已经成为小朋友快乐的象征。

图片

图源：印尼网友INS

说到这儿，我就想起自己小时候，每次能吃一次开心乐园餐，那可是个大日子，要考了95分以上才能享受，可以说，蜜雪冰城将物美价廉、不做价格刺客，让每个人都能很容易享受快乐的文化，传递到了全世界。

图片

此前，中国全球化最成功的企业，都是一些互联网公司，科技公司，真正像麦当劳，Costco那样，能在全世界受到老百姓欢迎并输出文化的消费品公司，寥寥无几。

但蜜雪冰城肉眼可见的做到了，就像当年的可口可乐，麦当劳一样，很多国家的人，看到中国的雪王，就看到了物美价廉，传递快乐。

图片

也许就在10年后，雪王也会像麦当劳叔叔那样，成为一代人共同的记忆。

也许在20年，会有喝雪王长大的外国小朋友来到河南打卡，一边比耶一边说，“终于喝上正宗的雪王柠檬水了”。

这时候路过的我们会捂着嘴笑：“这有啥好打卡的，外国人真喜欢大惊小怪。”
