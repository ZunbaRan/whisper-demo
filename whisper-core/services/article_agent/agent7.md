**Agent 7: 最终润色与格式编辑师 (Final Polish & Formatting Editor)** (原 终稿编辑)
    * **目的:** 根据 Agent 6 的评论实施修订，进行最终的语言/语法检查，并确保完美的格式。
    * **输入:** Agent 5 的草稿, Agent 6 的评论报告, Agent 2 的风格指南 (供最终检查)。
    * **核心步骤与逻辑:**
        * **(人工或带有清晰指令的 LLM):** 实施 Agent 6 建议的修订。这可能涉及 LLM 的定向重写或手动编辑。
        * **(LLM 调用 - 校对):** 使用专门提示进行高精度校对的 LLM。
            * **示例 Prompt 片段:**
                ```prompt
                角色: 你是一位一丝不苟的校对员。
                背景: 以下是一篇文章的最终草稿。
                文章文本: "[粘贴接近最终的文本]"
                任务: 仔细校对文本，检查任何语法错误、拼写错误、标点错误、不自然的措辞或打字错误。列出所有建议的修正。
                输出格式: 修正列表或高亮显示更改的修正后文本。
                ```
        * **(代码/手动):** 应用适合发布平台的最终格式 (Markdown 标题、粗体、列表、引用块)。从 Agent 5 的建议中选择最终标题或进行优化。
    * **输出:** 最终的、经过润色、校对和格式化的文章，可供发布。
    * **工具:** LLM API, 文本编辑器/代码 (用于格式化)。
