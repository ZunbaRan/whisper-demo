 **Agent 6: 批判性审阅与一致性检查器 (Critical Reviewer & Consistency Checker)** (新增 - 质量控制)
    * **目的:** 作为客观的质量控制步骤，在最终润色前检查连贯性、一致性和整体效果。
    * **输入:** Agent 5 的修订稿, Agent 1 的摘要, Agent 2 的风格指南, 选定的角度 (Agent 2.5), 互动目标。
    * **核心步骤与逻辑:**
        * **(LLM 调用):** 提示 LLM 进行整体审阅。
        * **示例 Prompt 片段:**
            ```prompt
            角色: 你是一位经验丰富的编辑，对细节、风格一致性和说服力有敏锐的洞察力。
            背景:
            - **文章草稿:** "[粘贴 Agent 5 的草稿]"
            - **原始目标:** 将播客摘要 [提及 Agent 1 的关键点] 转化为一篇使用角度 '[选定角度]'、模仿 [作者姓名] 风格 (风格指南如下) 的文章，并融入 [提及互动目标]。
            - **风格指南:** [粘贴风格指南]
            任务: 根据以下标准批判性地评估草稿：
            1.  **内容保真度:** 是否准确反映了播客的核心信息？
            2.  **角度执行:** 选定的角度是否在全文中得到了清晰的阐述？
            3.  **风格遵循度:** 与 [作者姓名] 风格指南的匹配程度如何？指出具体的偏差。
            4.  **互动元素整合:** '焦虑/争议'元素是否有效且合乎道德地整合了？感觉自然还是生硬？
            5.  **连贯性与流畅性:** 文章结构是否合乎逻辑？过渡是否平滑？
            6.  **整体影响力:** 文章是否有说服力、有见地，并可能吸引目标受众？
            输出格式: 提供一份结构化的评论报告，包含具体的例子和可操作的改进建议。给出一个整体成功度的信心评分 (1-10)。
            ```
    * **Output:** 一份详细的评论报告，包含最终修订建议。
    * **工具:** LLM API。
