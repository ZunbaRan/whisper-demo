**Agent 5: 互动与争议注入师 (Engagement & Provocation Injector)** (原 传播策略师)
    * **目的:** *有道德地*、*风格恰当地* 策略性地融入“焦虑”或“争议”元素，以提高互动性和分享性。
    * **输入:** Agent 4 的增强稿, Agent 2 的风格指南, 关于所需互动元素*类型*和*强度*的明确指示 (例如，“ subtly 强调不作为的代价”，“将一个关键点构建为对普遍做法的挑战”)。
    * **核心步骤与逻辑:**
        * **(LLM 调用 - 定向重写):** 将 LLM 的注意力集中在确定适合注入互动元素的特定部分或观点上。
        * **示例 Prompt 片段:**
            ```prompt
            角色: 你是一位有说服力的作家，擅长在遵循特定作者风格的同时，巧妙地融入激发互动的心理触发点。
            背景:
            - **文章草稿章节:** "[粘贴 Agent 4 输出的相关章节]"
            - **目标作者风格指南:** [粘贴风格指南]
            - **本章互动目标:** [例如, '放大采纳此建议的紧迫感', '围绕此观点引入一个有争议的问题']
            任务: 重写提供的章节以实现互动目标。
            1.  巧妙地融入能制造 [紧迫感/焦虑/稀缺感/对规范的挑战/辩论点] 的语言。
            2.  确保更改与周围文本平滑融合。
            3.  **关键：保持 [作者姓名] 风格指南中定义的语气、词汇和句式结构。** 互动元素应感觉像是作者*可能*会写出来的。
            4.  **道德检查:** 避免错误信息、有害的刻板印象或过度激进的恐惧营销。将其构建为强烈的观点或具有挑战性的问题。
            输出格式: 提供重写后的章节。
            ```
        * **(LLM 调用 - 标题/钩子生成):** 基于*最终*修订内容，生成多个引人入胜的标题和社交媒体钩子，融入互动角度。
    * **输出:** 融入了互动元素的修订稿，外加一份标题/钩子选项列表。
    * **工具:** LLM API。
