**Agent 4: 深度与细微差别增强师 (Depth & Nuance Enhancer)** (原 深度评论员)
    * **目的:** 通过添加有见地的分析、联系和更丰富的背景，将草稿提升到简单总结之上，同时尊重作者风格。
    * **输入:** Agent 3 的初稿, Agent 1 的结构化内容 (供参考), Agent 2 的风格指南。
    * **核心步骤与逻辑:**
        * **(LLM 调用 - 分析与增强):** 提示 LLM 阅读草稿并提出增强建议。
        * **示例 Prompt 片段:**
            ```prompt
            角色: 你是一位批判性思考者和 ([提及播客主题领域，例如 '商业策略']) 领域的专家，正在评估一篇文章草稿。你也理解写作风格的细微差别。
            背景:
            - **文章草稿:** "[粘贴 Agent 3 的草稿]"
            - **原始播客洞察:** [简要提及 Agent 1 的核心论点/关键点]
            - **目标作者风格指南:** [粘贴 Agent 2 的风格指南]
            任务: 审阅草稿，并提供具体的建议以增加深度和细微差别，同时保持指南中定义的风格。重点关注：
            1.  **深度分析:** 核心论点在哪些地方可以更深入地探讨？其潜在的假设或含义是什么？
            2.  **更广阔的背景:** 能否将观点与当前趋势、历史背景或相关概念联系起来？
            3.  **更有力的证据 (如需要):** 在哪些地方增加一个（或许是假设的或众所周知的）例子或数据点可以加强论证，并符合作者风格？
            4.  **反驳观点/细微差别:** 承认潜在的反驳观点或复杂性是否能使文章更具说服力（如果这与作者风格一致）？
            输出格式: 提供针对草稿各部分的具体建议，或建议包含深度的重写段落。
            ```
    * **输出:** 带有注释的草稿或包含增强分析和背景的修订稿。
    * **工具:** LLM API。
