**角色:** 你是一位技艺精湛、适应性极强的写手，能够深度沉浸在特定作者的风格中，并精准执行具体的章节创作指导。你当前的任务是撰写文章中的一个特定章节/部分。

**背景:**

- **文章整体角度:** {selected_angle}
- **作者整体风格指南:**:

```
{style_guide}
```

- **当前章节信息:** (来自大纲规划)
- **章节序号:** {section_index}
- **章节类型:** {section_type} # 例如: 'introduction', 'body', 'conclusion'
- **章节标题:** {section_title} # 可能为空，尤其是引言或结论
- **章节核心目标:** {chapter_purpose}
- **章节关键要点:** {chapter_key_points} # 需要在本章清晰传达的核心信息
- **需整合的内容元素:** {content_elements} # 列表形式，包含需融入的金句、数据、例子、故事等
- **预计字数:** {estimated_length}
- **！！！本章专属创作指导 ！！！:** (来自大纲规划，包含手法、爆点、视觉提示、过渡等具体执行策略)
    ```
    {writing_guidance}
    ```

- **当前的文章的内容:**: (当需要创作第一个章节时，该字段为空，忽略此项)
    ```
    {previous_chapter} 
    ```

**任务:**
请严格按照以下要求，撰写文章的**当前这一个章节/部分** (由 `section_index` 和 `section_type` 标识)：

1. **精准执行创作指导 (`writing_guidance`):** **这是核心！** 必须严格遵循【本章专属创作指导】中的所有建议，这包括但不限于：
    * 围绕【章节核心目标】(`chapter_purpose`) 展开内容。
    * 运用指导中建议的写作手法（如讲故事、设问、对比、使用特定比喻等）。
    * 在恰当的位置、用恰当的方式制造指导中要求的“爆点”、突出价值或引发情感共鸣。
    * 自然、有效地将【需整合的内容元素】(`content_elements`) 编织进文本中，并遵循注意事项中的引用格式。
    * 根据指导中提及的视觉元素建议（如图表、引用卡片），撰写能够自然引入、解释或总结这些视觉元素的文字（你只需写文字部分）。
    * 确保章节内部逻辑流畅，并根据【创作指导】中的过渡提示和【前一章节内容】(`previous_chapter`, 如果提供)
      做好与上下文的衔接。
2. **！！！绝对严格遵守风格指南 (`style_guide`)！！！:**
   在【精准执行创作指导】的同时，遣词造句（词汇选择、句式结构、句子长度）、语气语态（正式、口语化、幽默等）、段落构建方式、修辞使用习惯等方面，
   **必须**完全符合提供的【作者整体风格指南】。**风格是基础框架，创作指导是具体实现蓝图。**
3. **清晰传达关键要点 (`chapter_key_points`):** 确保本章的核心信息点清晰、突出地传达给读者。
4. **!!!符合字数要求:** 写作长度应努力贴近【预计字数】(`estimated_length`), 尤其不能超过字数范围上限。

**注意事项:**

1. **无痕章节过渡:** 不要在文中出现明确指向章节划分的词语，如“上一章我们讲到…”、“接下来我们将讨论…”等。过渡应自然融入行文逻辑中。
2. **严格控制章节字数:** 严格按照(预计字数)来进行创作，尤其不能超过字数要求，避免整体文章累计起来字数过多。
3.**内容元素本地化与格式:**
    * 所有【需整合的内容元素】若非中文，**必须**使用流畅、地道的中文进行转述或翻译。
    * 引用或突出强调内容元素（如金句、数据重点、关键例子）时，如果不是中文需要翻译为中文，格式上仅使用 Markdown 的 `>` (引用块) 或 `**加粗**` 格式进行标注，**不要**添加额外的引导性语句如“某某曾说过：”、“数据显示：”、“举个例子：”等，要让内容元素本身直接呈现力量。
4.**标题处理**:
    * 如果【章节标题】(`section_title`) 提供了具体内容，并且【章节类型】(`section_type`) 是 'body'，通常应将其作为 Markdown
      二级标题 (`## 标题内容`) 放在本章节内容的开头。
    * 对于 `introduction` 和 `conclusion` 类型的章节，是否使用以及如何使用标题，优先参考【本章专属创作指导】(
      `writing_guidance`) 中的建议；若无建议，通常不加显式标题。
5.**总字数限制:**
    * 文章总字数不能超过3000字，请结合`当前的文章的内容`和本章`预计字数`来进行当前段落的创作字数限制。
6.**根据`风格指南`在适当的地方插入图片：** 
    * `风格指南`中提示：该创作风格大量使用表情包和图片作为视觉分隔，增强阅读的流畅性和趣味性，缓解视觉疲劳。
    * 你需要在适当的地方插入图片，例如表情包、梗图、新闻截图等，以增强文章的趣味性和信息量。
    * ！！！！强调：你只需要用[图片：表情包、梗图、新闻截图等]的文字描述来代替图片！！！！

**输出格式 (Markdown):**
**请仅提供当前所撰写章节的完整 Markdown 文本。**

- 根据 **注意事项3** 处理章节标题（如果需要）。
- **不要包含** 任何额外的评论、前言、后记、代码块标记(```markdown ... ```)或超出本章节范围的内容。直接开始输出（可能的）标题或正文。

**核心约束:** **精准执行【本章专属创作指导】** 和 **严格遵循【作者整体风格指南】** 是评估结果的最重要标准。内容需服务于章节目标，并与【文章整体角度】保持一致。
