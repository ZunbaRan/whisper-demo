**Agent 3: 结构化草稿与风格注入师 (Structured Draft & Style Infusion)** (强化角色)
    * **目的:** 创建一个连贯的初稿，不仅包含播客的关键元素，而且根据风格指南*主动应用*目标作者的风格。
    * **Input:**
        * Agent 1 的结构化内容输出。
        * Agent 2 的“风格指南”。
        * Agent 2.5 选定的角度/引子。
    * **核心步骤与逻辑:**
        * **(LLM 调用 1 - 大纲细化):** 基于选定的角度和播客结构大纲 (来自 Agent 1)，要求 LLM 创建一个更详细的文章大纲，并在逻辑位置整合关键引言、示例和数据点。
        * **(LLM 调用 2 - 按章节注入风格起草):** 遍历详细大纲，提示 LLM 撰写每个部分。*关键：在每个部分的 Prompt 中都包含风格指南。*
            * **示例 Prompt 片段 (针对一个章节):**
                ```prompt
                角色: 你是一位熟练的作家，负责以 [作者姓名] 的特定风格起草文章的一个章节。
                背景:
                - **文章角度:** [Agent 2.5 选定的角度]
                - **本章目标:** [描述这个具体章节的目的，来自详细大纲，例如 '解释播客讨论的核心问题']
                - **本章关键内容:** [包含来自 Agent 1 输出的相关引言、数据或摘要点]
                - **[作者姓名] 风格指南:** [在此粘贴 Agent 2 的相关部分或完整风格指南]
                任务: 撰写文章的这一章节（大约 [字数] 字）。
                1.  使用提供的关键内容达成章节目标。
                2.  **严格遵守** [作者姓名] 风格指南中关于语气、句式结构、词汇和修辞手法的规定。
                3.  如果提供了前一章节的文本，请确保过渡平滑。
                输出格式: 仅提供本章节的文本。
                ```
        * **(代码):** 将生成的部分拼接在一起。
    * **输出:** 一份完整的文章初稿，尝试遵循选定角度和目标作者的风格。
    * **工具:** LLM API, Python (用于编排章节生成和拼接)。
