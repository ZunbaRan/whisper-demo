1.  **Agent 1: 播客内容解构师 (Podcast Content Deconstructor)** (强化细节)
    * **目的:** 精确、高效地从播客文字稿中提取原始精髓、结构和关键可复用组件。
    * **输入:** 播客文字稿 (文本文件)，可选元数据 (单集标题、嘉宾姓名、主要话题)。
    * **核心步骤与逻辑:**
        * **(代码可选但推荐): 预处理:** 使用 Python 脚本进行：
            * 移除时间戳、说话人标签 (如果不需要或不一致)。
            * 文本规范化 (例如，转小写，移除过多标点)。
            * 尝试基础填充词移除 (例如，“嗯”、“啊”、“这个”、“那个”) 使用正则表达式或简单列表。*注意：过度移除可能改变自然语感。*
            * 将文字稿分割成逻辑块 (例如，基于原始转录识别的停顿，或如果已格式化则按段落)。如果文字稿很长，这有助于管理后续 LLM 调用的 Token 限制。
        * **(LLM 调用 1): 核心主题与论点识别:**
            * 将清理后的文字稿 (或分块) 输入 LLM。
            * **示例 Prompt 片段:**
                ```prompt
                角色: 你是一位专注于总结口语内容的专家级分析师。
                背景: 以下是一期关于 [提及主题，例如 '创业者个人生产力'] 的播客文字稿。
                文字稿: "[在此插入清理后的文字稿片段]"
                任务: 分析提供的文字稿片段，并识别：
                1.  讨论的中心主题或主要议题。
                2.  发言者提出的主要论点或主张。
                3.  涵盖的关键子主题。
                输出格式: 为每个点 (1, 2, 3) 提供简洁的摘要。
                ```
        * **(LLM 调用 2): 关键元素提取 (注重可复用性):**
            * 将清理后的文字稿 (或分块) 输入 LLM。
            * **示例 Prompt 片段:**
                ```prompt
                角色: 你是一位细致的内容提取者，专注于识别对话中的有影响力元素。
                背景: 分析以下播客文字稿片段： "[在此插入清理后的文字稿片段]"
                任务: 精确提取以下元素（原文引用或准确总结）：
                1.  **金句 (Golden Quotes):** 识别并列出那些特别有见地、令人难忘、有力或完美概括核心观点的原话句子或短语。目标是提取适合直接在文章中使用的引言。
                2.  **可行动建议/要点 (Actionable Advice/Takeaways):** 列出发言者建议的清晰、简洁的建议或可执行步骤。
                3.  **例证/案例研究 (Illustrative Examples/Case Studies):** 简要总结用于阐述观点的任何故事、轶事、具体的公司案例或个人经历。注明该例子支持的核心观点。
                4.  **关键数据/统计 (Key Data/Statistics):** 列出为支持主张而提及的任何具体数字、百分比或数据点。
                输出格式: 为每个类别（金句、可行动建议、例证、数据）使用 Markdown 列表。对于例证，将摘要与其阐述的观点配对。
                ```
        * **(LLM 调用 3): 结构大纲分析:**
            * 将清理后的文字稿 (或来自调用1的主题/子主题摘要) 输入 LLM。
            * **示例 Prompt 片段:**
                ```prompt
                角色: 你是一位逻辑思考者，擅长辨别论证结构。
                背景: 基于从播客文字稿中提取的主题和关键点 ([可选择提供来自调用1的主题])，判断原始讨论可能的逻辑流程或叙事结构。
                任务: 概述其结构。例如：
                    - 提出问题 -> 分析原因 -> 提供解决方案 -> 举例说明
                    - 概念介绍 -> 解释说明 -> 案例1 -> 案例2 -> 结论
                    - 按时间顺序叙事 -> 关键经验教训
                输出格式: 提供一个代表所识别结构的项目符号列表。
                ```
    * **输出:** 一个结构化的数据对象 (例如，JSON 或 Python 字典)，包含：
        * `main_theme`: 字符串
        * `thesis`: 字符串
        * `sub_topics`: 字符串列表
        * `golden_quotes`: 字符串列表
        * `actionable_advice`: 字符串列表
        * `examples`: 对象列表 (`{summary: string, illustrates: string}`)
        * `data_points`: 字符串列表
        * `structure_outline`: 字符串列表
    * **工具:** LLM API, Python (用于预处理)。
