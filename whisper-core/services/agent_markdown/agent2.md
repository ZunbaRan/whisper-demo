2.  **Agent 2: 作者风格分析器 (Author Style Analyzer)** (解决 Token 限制问题)
    * **目的:** 从大量的文章语料库中深入理解并编码目标作者的写作风格。
    * **输入:** 目标作者的文章集合 (几十篇)。
    * **核心步骤与逻辑 (解决 Token 限制):**
        * **(代码):** 编写 Python 脚本遍历每篇样本文章。
        * **(代码 + 每篇文章的 LLM 调用):** 对于每篇文章，将其文本发送给一个 LLM 实例，使用特定 Prompt 来分析*该篇*文章的风格。
            * **示例 Prompt 片段 (单篇分析):**
                ```prompt
                角色: 你是一位文学分析师，专注于识别独特的写作风格。
                背景: 分析以下由 [作者姓名] 撰写的文章： "[在此插入完整文章文本]"(文档段落中包含图片标识，这里不贴出具体图片，只是描述图片的大概内容，图片是文章的一部分，分析文风的时候也要考虑图片插入的时机和作用)
                任务: 识别并描述这篇具体文章的风格特征，重点关注：
                1.  **语气与语态 (Tone & Voice):** (例如, 正式, 非正式, 讽刺, 权威, 共情, 客观) - 提供关键词。
                2.  **句式结构 (Sentence Structure):** (例如, 长短句结合, 主要是复杂句, 简洁直接) - 描述模式。平均句长估计？
                3.  **词汇选择 (Vocabulary):** (例如, 技术术语, 口语化表达, 富有感染力的形容词, 简洁易懂) - 列出值得注意的词语选择或类别。
                4.  **修辞手法 (Rhetorical Devices):** (例如, 隐喻, 类比, 反问, 重复, 讲故事) - 列出观察到的手法。
                5.  **段落与流畅性 (Paragraphing & Flow):** (例如, 短小精悍的段落; 详细的长段落; 过渡词的使用) - 描述结构。
                6.  **开头与结尾模式 (Opening & Closing Patterns):** 作者通常如何开始和结束文章？ (例如, 轶事, 大胆陈述, 提问, 总结)
                7.  **文章标签(tag):** 这篇文章大概属于什么类型的文章？ (例如：技术, 商业, 情感, 历史, 教育) 
                输出格式: 提供结构化输出 (例如, JSON)，包含每个类别的描述。
                ```
        * **(代码):** 存储*每篇*文章的结构化风格分析输出 (例如, JSON)。
        * **(代码 + llm调用):** 分别将近似tag(可以利用llm来识别哪些内容的tag是近似的)的内容进行聚合结果。计算频率 (例如，最常见的语气，所有文章的平均句长，常用的修辞手法)。识别一致的模式与变化之处。
        * **(用于综合的 LLM 调用):** 将*根据tag聚合后的统计摘要*以及可能的*代表性片段* (例如，代码识别出的常见句式结构或修辞手法的例子) 输入到最终的LLM 调用中。
            * **示例 Prompt 片段 (综合生成风格指南):**
                ```prompt
                角色: 你是一位大师级写作指导，将风格分析综合成一份实用的指南。
                背景: 基于对 [作者姓名] 的 [文章数量] 篇文章的分析，观察到以下模式： [粘贴聚合数据: 常见语气, 平均句长, 常用手法, 词汇模式, 结构习惯等]。代表性例子包括： [粘贴几个关键例子]。
                任务: 创建一份全面的“风格指南”，用于模仿 [作者姓名] 的写作。这份指南应具有可操作性，并提供如何模仿其风格的清晰说明。涵盖语气、语态、句式结构、词汇、修辞策略、结构、开头/结尾。利用提供的数据和例子来构建指南。
                输出格式: 一份详细、结构良好的 Markdown 文档，标题为“[作者姓名] 风格指南”。
                ```
        * **输出:** 根据近似的tag分别生成详尽的、可操作的“风格指南”文档 (Markdown 或类似格式)，描述作者典型的语气、词汇、句式结构、修辞手法和结构模式。
    * **工具:** LLM API
